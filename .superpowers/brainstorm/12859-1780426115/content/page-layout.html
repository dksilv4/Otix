Games Page Layout

What sections live on the main games page? (from top to bottom)

A

Dashboard-Style

Storage bar (total used/free per drive) → Hero section (featured matched game, large artwork) → Recently Played row → All Matched Games grid → Unmatched Games compact list

Focus on discovery + visual polish. Like Steam library.

B

Launcher-Style

Custom title bar (search + settings) → Tab strip (All / Matched / Unmatched / ISOs) → Storage breakdown per-game bar chart → Grid view (filterable, sortable)

Functional first. Like Playnite or GOG Galaxy. Faster scanning, more controls.

C

Minimal Grid

Storage bar (compact ring chart) → Search bar → Grid with a toggle: Show Matched First / Show All. Matched games get poster art & logo; unmatched get icon + gradient. Inline "Match" button on unmatched cards.

Simple, single scroll. Everything in one view.
