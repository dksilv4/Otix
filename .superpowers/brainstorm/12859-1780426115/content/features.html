Feature Checklist

What features belong in the games launcher? Click all that apply.

S

Storage Breakdown

Per-game disk size, per-drive usage bar, total library size. Show individual game install sizes (read from disk).

R

Recently Played

Show last played games with timestamps. Track via existing game-detector.ts. "Continue" button for recent.

P

Play Time Tracking

Per-game play time (total hours). Show on game cards. Sort by most played.

F

Favorites

Star/favorite individual games. Filter by favorites. Persisted to local DB.

C

Right-Click Context Menu

Launch, Open Install Folder, Show in File Explorer, Unlink Match, Run As Admin, Create Desktop Shortcut.

O

Advanced Sorting

Sort by: Name, Install Date, Last Played, Size (largest first), Platform, Match Status.

U

Update Scanner

Check for game updates via NZBPlanet. Show available updates on matched games. One-click download.

L

Library Sync

Rescan button (existing). Auto-scan on startup. Notification when new games detected.

I

ISO Installer Integration

ISO tab shows all scanned ISOs with install button. Mount → Setup → Crack → Done workflow from current installer modal.

M

Match Games Flow

Auto-match on scan. Manual match modal from card context. Batch confirm suggestions.
