Game Card Design

Matched vs unmatched should look different. How should cards work?

A

Vertical Posters (Steam-style)

Matched games: tall 2:3 poster cards with full cover art, logo overlay, hover play button. Unmatched: same size, but with gradient background + game icon + "Match" badge. Consistent grid spacing, clear visual tiering.

Pros

  • Best visual hierarchy
  • Matches Steam/Playnite expectation
  • Artwork looks great

Cons

  • Less info visible per card
  • More scrolling
B

Horizontal Banner Cards

Wide 16:9 cards with game artwork, logo on left, info on right (size, platform, play time). Matched get artwork + logo. Unmatched get gradient + icon + "Click to match" hint. More dense, more info.

Pros

  • More info density
  • Better for storage + time stats
  • Good for wide screens

Cons

  • Less "shelf" feel
  • Harder to scan quickly
C

Hybrid: Large Poster + Compact List

Matched games: large vertical posters in a multi-row grid (hero treatment). Unmatched games: compact rows below — small icon, title, platform badge, "Find Match" button. Best of both — matched get art spotlight, unmatched don't waste space.

Pros

  • Spotlights matched games
  • Unmatched compact = less visual clutter
  • Clear visual separation

Cons

  • Two different layouts to maintain
