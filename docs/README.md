# Docs

This directory contains implementation plans and design specs.

> **Note:** This is not traditional API or user documentation — it is a working
> folder of planning artifacts generated during feature development.

## `plans/`

before or during the implementation sprint and documents the intended approach,
file changes, and acceptance criteria.

| `2026-09-18-frontend-prod-readiness.md` | Frontend production hardening |
| `factorio-blueprint-plugin.md` | Factorio blueprint plugin |

## `specs/`
Design specifications and API contracts corresponding to the plans above.
